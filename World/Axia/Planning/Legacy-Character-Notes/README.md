# Legacy character notes — noncanonical

**Nothing in this directory is Axia canon.**

These are the Markdown character notes that used to sit in a top-level
`Characters/` tab of the vault, kept here unchanged so the corpus is not
lost. They are reference and inspiration — largely notes on characters
from other settings — not statements about Axia, and no mechanic reads
them.

They have not been converted, reorganized, reformatted or parsed, and
they should not be. A canonical character is a validated
`character.json` under `../../../Vault/Axia/Characters/`, authored
deliberately. Heuristically converting prose into mechanics would invent
facts and attribute them to the setting.

Files here moved by path only: their bytes are identical to before the
move, verified by hash.
